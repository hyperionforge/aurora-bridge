# Aurora Bridge (Android) - context for a new Claude conversation

Attach this zip to a new chat and say: "This is my Aurora Bridge Android app - read CONTEXT.md and README.md, then here is what I want next: ..."

Origin: port of the 3-screen ESP32 "BRIDGE_SIMULATOR" (Waveshare 7" boards, ESP-NOW) to phones.
- web/ = the whole game (plain ES modules, no build step). Shared by the app, phone browsers, the TV page and the Chromecast receiver.
  - js/config.js (all constants/balance, station LAYOUTS, ORDERS), js/sim.js (Sim class = sim.h+missions.h+orders.h),
    js/host.js (lobby, station grouping, snapshots, relay protocol), js/world.js (client state + interpolation + Link),
    js/gfx.js (canvas immediate-mode LCARS UI, virtual 440px-high coordinates), js/app.js (phone shell),
    js/stations/{helm,tactical,common}.js (the 8 roles), js/viewscreen.js + js/tv.js (main viewer), js/sound.js (WebAudio synth).
  - index.html (phone), screen.html (TV in a browser), receiver.html (Chromecast CAF receiver), start.html (app home screen).
- android/ = Java app: MainActivity (WebView + window.AuroraNative bridge), RelayServer (pure Java HTTP+WebSocket relay),
  Discovery (NSD _aurorabridge._tcp), CastHelper + CastOptionsProvider (Cast sender; App ID entered in app Settings).
  Gradle copies ../web into assets at build time. AGP 8.7.3, Gradle 8.10.2, compileSdk/targetSdk 34, minSdk 24.
- server/dev-server.mjs = same relay in Node (PC hosting / tests). tools/relay-pc = runs the Java relay on a PC.
- tests/bots.mjs (crew bots, all missions), tests/e2e.mjs (headless Chromium multi-phone + TV, screenshots).
- Relay protocol: client->host "M cid json" (+J/L), host->relay "B json" / "T cid json" / "I json". Host must be loopback.
- Roles: each player toggles roles ('role' {tab}); one holder per role; start needs all 9 (NUM_CORE=9, captain included; the captain is one tab, T_CAPTAIN=8, shown as a banner in the lobby) held by online players and nobody idle; 'auto' = AUTO_SPLIT in config.js (includes 8). In game, app.picking shows the lobby until CONFIRM. CAPTAIN role (T_CAPTAIN=8) expands to tabs 8/9/10 (CAPTAIN status + first officer, ORDERS, HAILS) in js/stations/captain.js; only the captain may send CMD.ORDER; sim.captainMode set at START. The readout is also viewscreen mode STATUS (VM_STATUS=5).
- Messages: hello/role/auto/unclaim/cmd (client->host); welcome/lobby/f (fast 10Hz)/s (slow 2Hz)/ev/who/nohost/full (host->client).
- APK is built by .github/workflows/build.yml (also deploys web/ to GitHub Pages for the Cast receiver) or Android Studio.
- Galaxy (js/galaxy.js): 9 star systems (160k square each, star at centre, planets orbit from the game clock via planetPos/starPos, belts, nebulae, stations with civ owner + kind) joined by jump lanes. THE SILENT CHOIR is hidden until revealed. sim.loadSystem(i) spawns stations (slots 0 and 2+); NAV plots (CMD.PLOT 43: a=0 jump b=sys, a=1 intercept b=id -> P.jumpPlot/icPlot); HELM's JUMP DRIVE panel aligns and engages. sim.jumpVector(to) = galaxy-chart bearing; jumpBlock needs heading within 5 deg (charging aborts beyond 12; engaging cancels evasive). CMD.JUMP (35) charges 10s, needs: not MISSION mode, a lane, undocked, warp online, >22k from the star, no hostiles within 12k, 150 energy; transit sim.jumpTransit(to) = 6s x laneSlow(to) x ART drag of unsolved story relics (P.jumpLen), onJumpStart(to) hook; arrive() places the ship 66k out facing the origin.
- Modes: MODE_MISSION (classic 18 missions, Kalos only), MODE_SANDBOX (free voyage), MODE_CAMPAIGN. SELECT sends c=mode, d=campaign index (sim.selCamp). MODES_READY limits the lobby selector.
- Drawing: js/sysdraw.js (bodies, drawSystemLayer, drawGalaxy, drawStation per station kind, drawJumpTunnel). NAV tab has SYSTEM / LOCAL 20K / GALAXY (jump panel). Snapshots carry sys, mode, visited, revealed, jumpWhy and npc name/short/kind/civ.
- Salvage (js/cargo.js = materials, RECIPES, POI_DEF, ART, SYS_POIS, SYS_FIXED_ART): CT_POI contacts (n.poi = n.kind = PK_*), CMD SAMPLE 36 / EXTRACT 37 / REFINE 38 / USE 39 / ANALYSE 40 / JETTISON 41. P.cargo[9], P.arts [{a,uid,ident 0-2}], sim.fx(key) applies artefact effects. Repair teams use spares (25% per spare, 45% speed without). Chorus shards (Shroud/Cerulean/Orra derelicts+ruins) deep-analysed together reveal the hidden system. UI: SCIENCE HOLD + POI panel, DAMAGE CARGO & REFINERY.
- Dialogue (js/dialogue.js = CHARS cast, DIALOGS trees, STATION_DIALOG; js/portraits.js = faces, glyph runes, translator timing): sim.startDialog(key, fromId, ctx), presentNode, dialogReply (CMD.DREPLY 42 a=seq b=index), endDialog; msgs carry who/lang/dseq/dopt; slow snapshot has dlg {seq,key,who,from,left} and rep[civ]. sim.rep drives attitudeOf (stations change faction). Stations greet within 14k outside MISSION mode. kessariDemand(n, draal) -> 'demand' tree with 25s timeout; orranDuel/duelTick; rumour(); sim.after(sec, fn) timers in worldTick.
- Sandbox (js/voyage.js, installed onto Sim.prototype): contracts (sim.job; makeJob by giver civ: bounty/survey/rescue/salvage/deliver/courier; jobAccept/jobTick/jobDone/jobFail + hooks jobOnScan/OnDock/OnDestroyed/OnExtract/OnLeave/jobHandIn), director voyageTick -> randomEvent every 80-150s (traffic, kessari, inspect, mayday, capsule, trader, fleet). Extra dialogs: contract, freighter, vtrader, inspection, mayday, stranded. NPC ships can carry n.talk/n.talkCtx and n.destX/destY + leaveAtDest (AI_TRAVEL).
- Campaign (js/campaign.js, installed onto Sim.prototype): sim.camp {ch, step, t, f (choices), ...}; startCampaign(ch) (selType = chapter-1, capped by campSave.maxCh), campChapter, campStep(k) sets objective + campEnter, campTick per step, onArrive(to) builds each chapter's scene, dialogs c_* in DIALOGS, allies via AI_ALLY (8) + allyRetarget, campEnding(kind: free/seal/fleet/silence). CAMPAIGNS list (id/name/chapters/desc/blurb); saves per campaign via campSaveOf(id) / campMaxes(), host stores sim.campSave in localStorage 'aurora.campaign'. js/campaign2.js = THE ARGUS PARADOX (installArgus; argusStart/Tick/Arrive/OnScan dispatched when camp.id==='argus'; camp.lines bearing lines drawn by sysdraw.drawCampLines; campFlux() tachyon meter + CMD.CAMP 44 a=1 deploy stabiliser; npc.note shown on full scan; ARGUS purge answer B+C = multiples of 7.31 THz; Mercy is the smuggler). tests/campaign2.mjs walks it. Vault lock answer 3-2-7 (planets of Kalos, Halcyon's two suns, seven notes). tests/campaign.mjs walks it end to end.
- Voices (js/voice.js): Narrator watches msgs (who/lang/reply) and speaks only who-lines (name prefix stripped) and captain replies, stops when the dialogue ends / viewer leaves COMMS. Engines: WebVoice (speechSynthesis; TV page), NativeVoice (AuroraNative.speak -> phone TextToSpeech) and CastVoice (AuroraNative.speakToCast: CastSpeech.java synthesizeToFile -> 16kHz mu-law base64 chunks {t:'tts'} over the Cast channel -> js/ttsplayer.js on receiver.html; {t:'ttsstop'}). Per-speaker voices in WHO/RACE, captain replies in CAPTAIN_VOICE. Sounds: js/sound.js WebAudio synth (reverb, charge hums via sound.update(w)). gfx.js polyfills ctx.roundRect (old Chromecasts) and has opts.safe overscan margin (receiver uses 0.04). receiver.html reports {t:'voice', ok} to the sender (CastHelper message callback -> window.onCastMessage); phone setting aurora.voice auto/on/off.

- Orbits/edges (js/orbit.js): no gravity; planets never block warp or jumps. An "orbit" = helm AUTOPILOT a=3 (AP_ESCORT) b=100+planet: P.apPlanet, P.escA; the autopilot circles round the planet if the station is on the far side, holds orbitPoint (ORBIT_K=2.4r) matching planetVel; within ORBIT_OK (900m) P.orbitPl=i (+sim.onOrbit if defined). CMD.PLOT a=2 b=planet -> P.orbPlot. Planets move slowly (PERIOD_SCALE=6) and fit inside the grid. Out of bounds: outDepth()>0 runs P.oobT; OOB_WARN 30s then OOB_DEAD 60s -> warp core breach (FAIL_BREACH); drawOobBanner is a strip at the top of the viewer / bottom of helm's compass, drawEdgeFrame darkens off-grid on maps. Safe spawns: sim.spotClear/safeSpot (star, edge, planets over the next 60s, ships) used by arrive() and resetPlayer. Warp continuous 0-6 capped by warpCap()=4*eff(warp); impulse capped by impulseCap(); P.throttle is an absolute % of IMPULSE_TOP clamped each tick to the cap (power moves the limit, not the set speed).
- Shield bubble: P.shRange 0..1 from the SHIELDS slider (CMD.SHRANGE 47, a=0..100, b=1 on release) -> bubbleR = 600..3000; shK = 1+1.5t shield drained per point stopped (damagePlayer and absorb). drawBubble = rim glow per quarter with seams. Helm AP_ESCORT=3 (CMD.AUTOPILOT a=3 b=id) holds 900m off a friendly ship's starboard side, matching speed; sim.sheltered(n)/absorb() put damage meant for friendlies inside it onto our shields (damageNpc, and hazard torpedoes hit the bubble edge). sysdraw.drawBubble draws it (tactical view, SHIELDS station).

- Ground sites (js/ground.js): CT_GROUND=7 contacts from GROUND[sys][planet]; they ride with the planet (groundPlace), are visible within GROUND_SEEN_K (8) radii of the planet or 0.75 x sensor range, and can be hailed whenever visible - beaming cargo needs orbit (P.orbitPl, sim.xferOk); generic g_* dialogs. - js/pulsar.js = PULSAR RESCUE (MT_PULSAR=7, NUM_MT=8; installPulsar). - Speech is off (voice.js VOICES_ON=false); the viewer keeps the forward view with pushed screens as an overlay (viewscreen.js VIEW_OVERLAY).
- Momentum flight: playerTick keeps P.vx/vy at impulse. Thrust is along the heading up to the throttle speed; assisted (P.autoBrake, CMD.AUTOBRAKE 48, or any autopilot, or docking) steers the velocity onto heading*target; P.allStop (FULL STOP, waypoint arrival) brakes to 0. Over the impulse cap (e.g. out of warp) it sheds speed fast. impulseCap = IMPULSE_TOP(333) * eff/2. Bots turn auto brake on.
- NAV zoom windows: nav.zoom 3 = 4K (ship drawn to scale, SHIP_LEN 340m / art 154 units), 1 = 20K, 0 = SYSTEM, 2 = GALAXY. Buoys/surface sites never use the ship sprite (artFor falls back to the freighter).
